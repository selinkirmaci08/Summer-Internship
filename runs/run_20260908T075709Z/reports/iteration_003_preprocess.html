Split reasoning

Fold 3 train cutoff (2020-06-30) falls exactly within the post-regime period, giving 30 post-regime training rows. This is the minimum viable signal to learn the Monday pattern added on 2020-06-01. Cutting at 2019-12-31 (clean boundary) would revert to 0 post-regime training — the same error as the prior run (+8.5 MAE on Mondays).

Deployment simulation: Forecasting bread demand h=1 to 90 days ahead from an origin date in recent history. Model trained on historical patterns, evaluated on future demands it has not seen.

Val fairness: Fold 3 val (Sep–Dec 2020, 95 rows, fully post-regime) is the best proxy for the 2021+ holdout. It captures the post-regime Monday pattern and COVID recovery demand. It does NOT capture the full Gentse Feesten pattern (cancelled in 2020) or the ongoing demand decline into 2021+.

Regime boundary: Fold 3 train cutoff 2020-06-30 falls in the post-regime period. Train includes 30 days post-regime. Leaves the full Sep–Dec post-regime window for evaluation.

Alternative considered: Cutting at 2019-12-31 would give 240 val rows but 0 post-regime training — repeating run_20260904T140437Z's error. Rejected.

h=90 constraint: Only 5 scoreable fold-3 val rows. Training MUST use all 3 folds for h=90 model selection.

Month-of-Year Median Imputation for Weather; Structural Zero for Competitor

wx_Maximum_Temperature MAR

nulls 1,015 → 0method month-of-year medianfit on fold-3 train

Missingness is entirely explained by date < 2015-01-01 (weather coverage gap). Month-of-year median preserves Belgium's strong annual temperature seasonality (summer warm, winter cold) that a global median would flatten. Fit on fold-3 train rows only to prevent validation leakage. Confidence: 0.85.

wx_Precipitation MAR

nulls 1,015 → 0mean post-impute 1.246 mm/day

Same MAR mechanism as temperature (date < 2015 gap). Visual Crossing API repeats the daily total in every hourly row — aggregation uses mean across 24 rows (not sum). Month-of-year median imputation applied. Note: post-imputation mean (1.246 mm/day) is ~2× lower than prior run's value (2.68 mm/day); may reflect that month medians underrepresent actual pre-2015 precipitation. Non-blocking — see clarification slide.

comp_n_competitors_closed MCAR

nulls 2,594 → 0fill constant 0

VerlofConcurrent.csv records events (competitor holidays). A missing row means no competitor was on holiday — structural zero, not unknown. Dates outside the 2017-07-01 to 2020-09-15 coverage window also get 0. The comp_data_available indicator (1 within coverage window) separates known zeros from out-of-coverage zeros. Confidence: 0.95.

Agent-Initiated Findings

Weather parquet: use mean (not sum) for aggregation
Visual Crossing API repeats the daily total in each hourly row. Summing 24 copies produced 29.9 mm/day (13× Belgium's annual average). Fixed to mean. Affects Precipitation, Snow_depth, Wind_Gust.
VerlofConcurrent.csv uses ';' separator (not ',')
European CSV convention. Initial read produced a 2,357×1 dataframe. Fixed: sep=';', encoding='latin-1'. All downstream scripts must use these settings.
h=90 has only 5 scoreable val rows in fold 3
Dataset ends 2020-12-31; last usable h=90 origin is ~2020-10-02. Training must pool all 3 folds for h=90 model selection. A fold-3-only h=90 result is likely noise.
Fold 3 has only 30 post-regime training rows
~4–5 Monday observations. Model must learn Monday-level demand from a very small signal. Feature Engineering should not regularise the regime×Monday feature aggressively.
