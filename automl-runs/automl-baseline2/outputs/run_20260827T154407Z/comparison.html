Agentic vs AutoML on Bread Demand

Run 20260827T154407Z · Aernoudt Bakery, branch 01

Did the agentic pipeline beat off-the-shelf AutoML?

Five forecasting systems, scored on the same 10,752 held-out rows — 512 trading days × 21 horizons, December 2020 to February 2023. Same split, same tuning set, same rows. Nobody saw a test row before it was scored.

Yes, but narrowly — and not where you would expect. The agentic pipeline finishes first at MAE 43.51, ahead of B1 by 0.20 and of doing nothing at all by 1.66. Almost all of that margin was created by the feature-engineering node (−2.54 MAE); the training node's contribution (−0.20) is indistinguishable from noise.

Where the improvement actually came from

Each tier is handed a different amount of the agent's work and everything else is held fixed, so the gaps between them are attributable. Reading left to right: plain AutoML on the raw data, then the same search given the agent's engineered features, then the agent's own tuned model on those features.

The lever nobody has pulled yet

−11.51 MAE
Applying a running bias correction computed only from past test dates takes the agentic model from 43.51 to 32.00. That is roughly five times the entire agent-versus-AutoML gap, and the run's own diagnosis node had already found it — it was deliberately kept out of the model artifact, because freezing a constant would destroy the adaptivity that makes it work.

What to take from it

  • Protect the feature-engineering node. It produced the only improvement in the comparison that survives contact with the test set.
  • The training node is not paying for itself here. Fifteen minutes of FLAML on identical features matched eleven iterations of recorded reasoning. The agent's model did win on robustness grounds — it looked worse on validation (26.59 vs 24.83) and better on test, which is exactly the trade its reasoning claimed to be making.
  • Use the naive for the week ahead. At h=1–7 it beats every model by about 5%. Running a model there costs accuracy.
  • The long horizons are the agentic pipeline's real win. +15.4% over naive at h=364, and it is the only system that stays ahead all the way out.
  • Fix the level before touching the model. The bias correction is worth more than every modelling decision in this comparison combined.
